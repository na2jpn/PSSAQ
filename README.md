## BW / NR

メイン画面下部の「受信フィルター」で操作。

- **BW：50 / 100 / 220 / 500 / 1000 Hz**。
  選択した受信周波数を中心とした全幅。初期220 Hzは従来の±110 Hzと同じ。
  受信モニター音とCWデコードに適用し、FFTの薄い帯で選択範囲を表示。
  保存WAVの再解析にも選択BWを使用。
- **NR：OFF / 弱 / 中 / 強**。
  スペクトルの局所的な雑音推定による簡易NRをモニター音だけに適用。
  初期OFF、ON時の追加遅延は約32 ms。
  弱い信号や速いCWではOFFと聞き比べて調整する。
  目的CWと同じ周波数の妨害波を分離する機能ではない。
- 切り替えても録音と表示済みデコードは維持。BW切替時には途中までのCW判定をリセット。
- **録音はDSP処理前の生入力PCMを保存**。NRはデコード経路へ入れない。
- 出力確認音はBW/NRを通さず、選択したAudio OUTとOUT音量で鳴る。

## Language

メニューの **Language → 日本語 / English / Русский** で即時切替。初期日本語。
選択は `config/settings.json` の `language` に保存。
メニュー、操作部、設定、状態・エラー表示、Aboutを翻訳。
実際のデバイス名やOSが返すエラーは元の表記で表示。

言語ファイルはEXE横の `language/ja.json`、`language/en.json`、`language/ru.json`。
UTF-8（BOMありも可）のJSON形式。`strings` 内の値が翻訳文、キーは日本語原文。
`{db:.1f}`、`{volume}`、`{count}`、`{name}` は変えずに残す。
編集は次回起動時に反映。欠落したキーや壊れたファイルはEXE内蔵の翻訳へフォールバック。

配布ZIPにもlanguageフォルダーを同梱。EXE単体でも不足ファイルを初回起動時に展開。
既存の言語ファイルは上書きしない。v0.6/0.7からEXEだけを更新しても使用可能。

## WindowsでのEXE生成

Python 3.11/3.12推奨。ソースZIPを新しいフォルダーへ展開し、そのフォルダーでPowerShellを開く。

```powershell
.\build-windows.ps1
```

実行ポリシーでブロックされる場合：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-windows.ps1
```

依存導入 → テスト → ビルド → 完成EXEの起動検査 → 配布ZIP作成を順に実行。
生成先は `release/PSSAQ.exe` と **`release/pssaq_v0.93.zip`**。
`PSSAQ.spec` を使うこと。SciPyの動的読み込み対策、アイコン、背景、言語ファイル、更新スクリプトを同梱する。
EXE横にconfig、recdata、masterdata、languageを作るため、書き込み可能な場所へ置く。

## 機能・使い方

- Audio IN / OUTを独立選択、48 kHz受信。入力チャンネル、CWトーン400–1000 Hzを設定可能。
- 17.2 kHzの帯域フィルター、FFT、CW包絡線、700 Hz等への周波数変換モニター。
- 自動/手動5–40 WPMの簡易CWデコード（実験的、誤判定あり）。
- REC / STOPで生入力PCMを `recdata/YYYYMMDD-HHMMSS.wav` へ録音。
- デコードを `masterdata/YYYYMMDD_ALL.txt` へ逐次追記。
- 「ファイル → 録音ファイルを開く」で48 kHz / 16-bit PCM WAVを再解析。

「設定 → Audio IN / Audio OUT 設定」で使用デバイスを選ぶ。
初回起動はモニター音ミュートOFF。その後は選択を保存。OUT音量を変えるか「出力テスト」で確認音が鳴る。
確認音はミュート中も鳴り、OUT音量0%では消音。録音・デコードには混ぜない。
同じデバイスが複数ある場合は [MME] / [Windows DirectSound] 等で識別可能。

17.2 kHzを実際に入力できるオーディオ機器が必要。48 kHzの表示だけでは通過帯域は保証されない。
CWデコードは微弱信号や雑音環境では誤判定する。

背景は `assets/saq_sunset.png`。`PREVIEW.png` は模擬信号の画面例で、実際のSAQ受信結果ではない。
背景イラストの生成時の指示は `assets/artwork_prompt.txt`。

## ソース起動・検証

`run_source.bat` で依存ライブラリを導入して起動。

```powershell
python -m unittest discover -v
```

v0.93では51件の単体・GUI統合テストを実施。
3言語、BWの近接信号減衰、NRの模擬CWに対する効果と連続処理、原音録音、設定復元、
更新の準備・独立起動環境、旧バックアップの限定削除を検証。
チェック欄の描画・マウス/キーボード操作、ミュート初期値と一度だけの移行、安定したICO保存先も検証。
周波数のマウス/キーボード操作、設定復元、実際のフィルターとミキサーの追従、原音録音の保持、
Aboutとアプリのアイコン一致、旧管理ICOの限定削除も検証。
文字コードはWindows日本語CP932を既定とするPath読み書きの模擬条件でも確認。
ビルド済みアプリの起動検査は、言語・画像・更新スクリプト・DSP・BW・NR・録音・確認音を確認する。
作成環境はLinuxであり、Windows PowerShellによる実際のEXE置換、Windowsタスクバーの実表示と音声機器の入出力は未実行。
Windowsでのビルド時にも完成EXEを自動起動し、専用のWindowsアイコン検査も実行する。
